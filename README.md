## Descripcion de los modulos

El proyecto esta compuesto por tres modulos y un archivo principal:

1. **matematicas.py**: Modulo encargado de operaciones matematicas como suma, resta, multiplicacion, division, potencias y validar si un numero es par. Tambien valida que los datos ingresados sean numeros.
2. **cuento.py**: Modulo que imprime una historia corta y permite cambiar el nombre del personaje, el lugar y un objeto. Al final muestra una moraleja.
3. **utilidades.py**: Modulo con funciones de apoyo para calcular el promedio de una lista, verificar pares y un mensaje de saludo.
4. **main.py**: Archivo principal que une los tres modulos anteriores y muestra un menu en consola para interactuar con cada uno.

## Como ejecutar el programa

1. Clonar el repositorio:
git clone https://github.com/paul-naim-lau-arevalo/modulo3_colaboracion_en_github.git

2. Entrar a la carpeta:
cd modulo3_colaboracion_en_github

3. Ejecutar el script principal:
python3 main.py

## Flujo de trabajo en GitHub
Cada integrante del grupo trabajo en una rama distinta. Luego creamos Pull Requests para revisar el codigo de los companeros, dejamos comentarios y correcciones, y al final fusionamos todo en la rama main.
